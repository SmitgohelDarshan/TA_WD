Concept of WWW

  • It stands for World Wide Web.
  • It is basically a system of internet servers that support specially formatted documents.
  • Users can access text, graphics, and animations over the Internet.
  • It is accessed through a web browser.

HTTP Protocol

  1. HTTP stands for Hypertext Transfer Protocol.
  2. HTTP is based on the client-server architecture.
  3. It follows a request-response model.
  4. 404 File Not Found is a common HTTP status code.
