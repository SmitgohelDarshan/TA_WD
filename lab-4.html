Basic HTML Document Structure

An HTML document contains the following basic elements:

<!DOCTYPE html> - Declares HTML5 document.

<html> - Root element of the webpage.

<head> - Contains page information.

<title> - Displays title in browser tab.

<body> - Contains visible webpage content.

Basic HTML Tags and Their Purpose

<h1> - Creates the main heading.

<p> - Creates a paragraph.

<a> - Creates a hyperlink.

<img> - Displays an image.

<br> - Moves content to the next line.

<hr> - Creates a horizontal line.

HTML

From Wikipedia, the free encyclopedia

HTML (HyperText Markup Language) is the standard markup language used to create web pages. It describes the structure of a webpage using different elements called HTML tags.

HTML is easy to learn and is supported by all modern web browsers. It works together with CSS for styling and JavaScript for interactivity.

History

HTML was created by Tim Berners-Lee in 1991. It has become the standard language for creating websites.
